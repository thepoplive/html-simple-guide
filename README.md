# HTML и CSS с нуля

Этот гайд для человека, который никогда не программировал и не знает, что такое тег, селектор или браузер-инструменты разработчика. Идём маленькими шагами, без сложных слов без объяснения.

## Что такое HTML и CSS вообще

Представь сайт как дом:
- **HTML** — это стены, комнаты, двери, окна. Он говорит браузеру: "здесь заголовок, здесь текст, здесь картинка, здесь кнопка". Это структура и содержимое.
- **CSS** — это отделка, покраска стен, мебель, шторы. Он говорит: "заголовок сделай синим, текст покрупнее, кнопку с закруглёнными углами". Это внешний вид.

Без CSS сайт будет работать, но будет выглядеть как голый текстовый документ — просто чёрный текст на белом фоне. HTML — обязателен, CSS — делает красиво.

## Что понадобится

Всего два инструмента, оба бесплатные:

1. **Текстовый редактор** — программа, где будешь писать код. Рекомендую [Visual Studio Code](https://code.visualstudio.com/) (в народе просто "VS Code") — скачай и установи, как обычную программу.
2. **Браузер** — Chrome, Firefox, Edge — что угодно, там будешь смотреть результат.

Больше ничего не нужно. Специальных программ для "создания сайтов" не существует — сайты пишутся в обычном текстовом файле.

## Шаг 1. Создаём первый файл

1. Создай на рабочем столе папку, например `my-site`.
2. Открой эту папку в VS Code (Файл → Открыть папку).
3. Внутри создай новый файл с именем `index.html` (именно `.html` на конце — это расширение говорит компьютеру, что это HTML-документ).

Важно: файл, который открывается по умолчанию при заходе на сайт, всегда называется `index.html`.

## Шаг 2. Пишем самый простой HTML

Вставь в `index.html` вот это:

```html
<!DOCTYPE html>
<html>
<head>
  <title>Мой первый сайт</title>
</head>
<body>
  <h1>Привет, мир!</h1>
  <p>Это мой первый сайт.</p>
</body>
</html>
```

Сохрани файл (`Ctrl+S`). Теперь найди этот файл на компьютере (через Проводник/Finder) и дважды кликни на него — он откроется в браузере. Ты увидишь заголовок "Привет, мир!" и текст под ним.

**Что тут происходит, по порядку:**

- `<!DOCTYPE html>` — служебная строка, которая говорит браузеру "это HTML5 документ". Пишется один раз в начале любого HTML-файла, просто как формальность, не задумывайся о ней.
- `<html> ... </html>` — весь документ обёрнут в этот "контейнер". Всё содержимое сайта находится внутри.
- `<head> ... </head>` — здесь лежит служебная информация, которая не отображается на странице напрямую (например заголовок вкладки браузера).
- `<title>Мой первый сайт</title>` — то, что видно в заголовке вкладки браузера.
- `<body> ... </body>` — здесь лежит всё, что реально видно на странице: тексты, картинки, кнопки.
- `<h1>Привет, мир!</h1>` — заголовок. `h1` значит "заголовок первого уровня" (самый крупный и важный).
- `<p>Это мой первый сайт.</p>` — обычный абзац текста (`p` от английского paragraph).

## Главный принцип HTML: теги-контейнеры

HTML состоит из **тегов**. Почти каждый тег открывается и закрывается:

```html
<p>Текст внутри</p>
```

`<p>` — открывающий тег, `</p>` — закрывающий (с косой чертой). Всё, что между ними — содержимое этого тега. Если забудешь закрыть тег — сайт может отобразиться криво, поэтому всегда закрывай то, что открыл.

Некоторые теги не имеют содержимого и потому не закрываются, например картинка:

```html
<img src="cat.jpg">
```

## Основные теги, которые нужны в 90% случаев

```html
<h1>Самый крупный заголовок</h1>
<h2>Заголовок поменьше</h2>
<h3>Ещё поменьше</h3>

<p>Обычный абзац текста.</p>

<a href="https://google.com">Ссылка на другой сайт</a>

<img src="картинка.jpg" alt="описание картинки">

<ul>
  <li>Пункт списка</li>
  <li>Ещё пункт</li>
</ul>

<div>Просто контейнер-блок, чтобы группировать элементы</div>

<button>Кнопка</button>
```

**Пояснения:**
- `<a href="...">текст</a>` — ссылка. `href` — это адрес, куда ведёт ссылка. Слово `href` пишется в кавычках внутри тега — это называется **атрибут**, дополнительная настройка тега.
- `<img src="..." alt="...">` — картинка. `src` — путь к файлу картинки (либо на компьютере, либо ссылка из интернета). `alt` — текст, который покажется, если картинка не загрузится (и его же читают программы для незрячих людей).
- `<ul><li>...</li></ul>` — список. `ul` = "unordered list" (список без номеров, с точками), внутри — пункты `<li>` (list item).
- `<div>` — просто пустой блок-контейнер без смысловой нагрузки, нужен чтобы группировать другие элементы и потом красить их через CSS.

## Шаг 3. Подключаем CSS

Создай ещё один файл рядом с `index.html`, назови его `style.css`.

В `index.html`, внутри `<head>`, добавь строку:

```html
<head>
  <title>Мой первый сайт</title>
  <link rel="stylesheet" href="style.css">
</head>
```

Это говорит браузеру: "возьми файл style.css и примени его оформление к этой странице".

## Шаг 4. Пишем первый CSS

В `style.css` напиши:

```css
h1 {
  color: blue;
}

p {
  font-size: 20px;
  color: gray;
}
```

Сохрани оба файла, обнови страницу в браузере (`F5`) — заголовок должен стать синим, а текст — серым и покрупнее.

**Как это устроено:**

```css
h1 {
  color: blue;
}
```

- `h1` — это **селектор**: к какому элементу применяем стиль (в данном случае ко всем тегам `<h1>` на странице).
- `{ ... }` — фигурные скобки, внутри — сами настройки.
- `color: blue;` — **свойство** (`color`) и **значение** (`blue`), разделённые двоеточием, в конце обязательно точка с запятой.

Так CSS и работает: "вот этому элементу — вот такие настройки".

## Основные CSS-свойства для старта

```css
p {
  color: red;              /* цвет текста */
  font-size: 18px;         /* размер текста */
  background-color: yellow;/* цвет фона */
  text-align: center;      /* выравнивание текста: left, center, right */
  font-weight: bold;       /* жирный текст */
}
```

Единица `px` (пиксели) — это просто "сколько точек экрана", стандартная единица размера в CSS.

## Классы — как красить не все теги подряд, а конкретные

Если хочешь стилизовать не все `<p>` на странице, а конкретный кусок текста — используется **класс**.

В HTML:

```html
<p class="важный-текст">Этот текст особенный.</p>
<p>А этот — обычный.</p>
```

В CSS (обрати внимание на точку перед именем класса):

```css
.важный-текст {
  color: red;
  font-weight: bold;
}
```

Точка перед именем в CSS значит "это класс, а не тег". Так стиль применится только к элементам с этим классом, а не ко всем абзацам подряд.

## Блочная модель — как элементы получают отступы и размеры

У каждого элемента на странице есть:

- **content** — само содержимое (текст, картинка)
- **padding** — отступ внутри элемента, между содержимым и его границей
- **border** — рамка вокруг элемента
- **margin** — отступ снаружи элемента, между ним и соседними элементами

```css
div {
  padding: 20px;        /* внутренний отступ */
  margin: 10px;         /* внешний отступ */
  border: 2px solid black; /* рамка: толщина, тип, цвет */
}
```

Это ключевая вещь для понимания, почему элементы на странице стоят так, а не иначе, и откуда берутся "пустоты" вокруг блоков.

## Собираем простую страницу целиком

Вот пример небольшой страницы-визитки, чтобы увидеть, как всё это работает вместе:

`index.html`:

```html
<!DOCTYPE html>
<html>
<head>
  <title>Моя визитка</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <div class="card">
    <h1>Иван Иванов</h1>
    <p>Начинающий веб-разработчик</p>
    <a href="https://t.me/example">Мой Telegram</a>
  </div>
</body>
</html>
```

`style.css`:

```css
body {
  background-color: #f0f0f0;
  display: flex;
  justify-content: center;
  padding-top: 50px;
}

.card {
  background-color: white;
  padding: 30px;
  border-radius: 10px;
  border: 1px solid #ddd;
  text-align: center;
  width: 300px;
}

h1 {
  color: #222;
}

a {
  color: #3366cc;
}
```

Тут новые вещи:
- `#f0f0f0`, `#222`, `#3366cc` — цвета в формате hex-кода (шестнадцатеричный код цвета), это просто ещё один способ задать цвет, точнее чем словом `blue`. Гуглится по запросу "color picker" — можно выбрать цвет мышкой и скопировать код.
- `border-radius: 10px` — скругляет углы блока.
- `display: flex; justify-content: center;` — это способ выравнивания элементов, в данном случае — "поставить блок по центру экрана". Flexbox — отдельная большая тема CSS, пока достаточно запомнить эту связку как готовый рецепт для центрирования.

## Как не бояться ошибок

Если что-то не отображается как надо:
1. Проверь, что все теги закрыты (`<p>` без `</p>`) — частая причина поломки вёрстки.
2. Проверь, что после каждого CSS-свойства стоит точка с запятой.
3. Открой инструменты разработчика в браузере (правый клик на странице → "Просмотреть код" / "Inspect") — там во вкладке Console видно ошибки, а во вкладке Elements можно даже прямо в браузере потыкать элементы и посмотреть, какой CSS к ним применяется.
4. Не переживай, если с первого раза не получилось красиво — вёрстка почти всегда получается методом "поправил-обновил-посмотрел" много раз подряд.

## Что учить дальше

Когда освоишься с этим:
- **Flexbox и Grid** — современные способы раскладывать элементы по странице (без них верстать неудобные "плавающие" макеты).
- **Адаптивная вёрстка (media queries)** — чтобы сайт нормально выглядел и на телефоне, и на компьютере.
- **JavaScript** — язык программирования, который добавляет сайту интерактивность (клики, анимации, отправка форм). HTML и CSS — это "внешний вид", JavaScript — "поведение".

Хороший бесплатный ресурс для практики после этого гайда — [MDN Web Docs](https://developer.mozilla.org/ru/) (официальная документация по HTML/CSS/JS, с примерами) и сайт [freeCodeCamp](https://www.freecodecamp.org/) с бесплатными интерактивными курсами.

## Главное правило

Программирование и вёрстка — это не про то, чтобы помнить всё наизусть. Даже опытные разработчики постоянно гуглят "как сделать то-то в CSS". Важно понимать логику (тег-контейнер, селектор-свойство-значение), а конкретные названия свойств можно всегда посмотреть в документации или спросить у той же нейросети.
